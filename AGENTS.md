# Notes for AI sessions and contributors

This repo is being redesigned as **bugu**. Before changing any UI:

1. Read `DESIGN.md`. It is the single source of truth and overrides your own taste.
2. Look at the approved prototypes in `design/reference/`.
3. Never push to `main` or merge. Work on a branch and open a pull request.
4. Design PRs change look and structure only, not logic, data, auth or payments.
5. Do not undo or restyle work from earlier design PRs unless `DESIGN.md` is updated first.

6. If another chat (for example the Supabase migration) works on this repo, read `HANDOFF.md` first and add your messages there.
